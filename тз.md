# Техническое задание: 2D-симулятор кафе для Android

## 1. Общее
- **Жанр:** симулятор кафе / менеджмент, 2D, портретная ориентация
- **Платформа:** Android (далее iOS не планируется)
- **Стек:** Phaser 3 (JavaScript), Capacitor (упаковка в APK/AAB)
- **Хранение данных:** localStorage (на старте), без сервера
- **Монетизация:** не в первой версии (позже возможна реклама AdMob и покупки)

## 2. Игровой цикл
1. Клиент приходит и делает заказ
2. Игрок готовит блюдо по рецепту
3. Блюдо подаётся клиенту, пока не истёк таймер терпения
4. Начисляются монеты (с учётом чаевых и штрафов)
5. Монеты тратятся на апгрейды, цикл повторяется

## 3. Механики заказов
- **Характер клиента:** торопыга (короткий таймер, щедрые чаевые), спокойный (долгий таймер, мало платит), привереда (требует конкретный сироп или без сахара). Характер показывается значком над головой.
- **Многошаговый заказ:** основа, добавка, подача. Ошибка на шаге ведёт к переделке и потере времени.
- **Записка-рецепт:** над клиентом висит три иконки, их нужно запомнить и собрать в правильном порядке.
- **Блокнот у кассы:** отдельный экран, заказ записывается и выдаётся позже. Чем больше очередь, тем выше риск перепутать.
- **Условия заказа:** «без молока», «двойной шот», «холодное мороженое». Проверяются при выдаче.
- **Рецепты-открытия:** смешивание ингредиентов в разном порядке открывает новые напитки.

## 4. Взбивание сливок
- Два способа: тап по кнопке или **тряска телефона**.
- Тряска включается в настройках, по умолчанию выключена.
- Тряска работает только на экране взбивания сливок.
- Прогресс показывается полоской или зелёной зоной.
- В настройках задаётся порог чувствительности тряски.
- Альтернатива (кнопка или ритм-мини-игра) доступна всегда.
- Источник данных: акселерометр через DeviceMotion (Capacitor для Android).

## 5. Случайные события
- **Блогер:** двойная оплата 30 секунд.
- **Поломка кофемашины:** мини-игра починки.
- **Проверка санэпидемстанции:** нужно поддерживать чистоту.

## 6. Прогресс и экономика
- **Апгрейды:** новый столик (50 монет), ускорение таймера (30 монет). Цена растёт после каждой покупки.
- **Ачивки и звёзды:** открывают декор и столики.
- **Постоянные клиенты:** запоминают любимый заказ, за угадывание даётся бонус.
- **Оффлайн-прогресс:** пассивный доход при возврате, ограничен 2 часами.

## 7. Сезоны и декор
- Сезонные напитки (тыквенный латте осенью, новогодние зимой).
- Смена декора и интерьера (мебель, цвет стен).

## 8. Экраны
1. **Главный экран:** стойка, 3–4 столика, очередь клиентов сверху, счётчик монет.
2. **Кухня:** кнопки ингредиентов и блюд.
3. **Блокнот:** заказы у кассы.
4. **Магазин апгрейдов.**
5. **Настройки:** тряска, порог чувствительности, звук.

## 9. Данные (JSON, localStorage)
```json
{
  "coins": 0,
  "tables": 2,
  "menu": ["coffee", "cake"],
  "upgrades": { "speed": 0, "tables": 0 },
  "settings": { "shakeToWhip": false, "shakeSensitivity": 0.5 },
  "lastSeen": 0
}
```

## 10. Нефункциональные требования
- Игра работает без интернета.
- Экран под телефон, 16:9 и 9:16 без обрезки важного.
- Сохранение при каждом изменении и при выходе.
- Поддержка Android 8.0 и новее.
